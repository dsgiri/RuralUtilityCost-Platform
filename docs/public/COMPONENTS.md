# Component Library Spec

## Philosophy
We use Tailwind CSS for utility-first styling. Components are functional, accessible, and lean.

## Core Components
- **Buttons:** `<Button />` (Primary, Secondary, Outline variants).
- **Inputs:** Accessible form fields with consistent focus states.
- **Cards:** Standardized containers for calculator results with `shadow-sm` and `border`.

## Icons
- Exclusively utilizing **Lucide React** for lightweight, consistent vector graphics.
